# Student Grade Calculator

## Project Description

The Student Grade Calculator is a Python-based console application that calculates the total marks, percentage, and grade of a student based on marks entered for different subjects. This project helps automate the grade evaluation process and demonstrates the use of basic Python concepts.

## Features

- Enter student details
- Input marks for multiple subjects
- Calculate total marks
- Calculate percentage
- Assign grades based on percentage
- Display student result summary
- Menu-driven interface

## Technologies Used

- Python
- Windsurf IDE
- Git & GitHub

## How to Run

1. Clone the repository.
2. Open the project in Windsurf.
3. Run the following command:

```bash
python main.py
```

## Grade Criteria

| Percentage | Grade |
|------------|--------|
| 90% - 100% | A+ |
| 80% - 89%  | A  |
| 70% - 79%  | B  |
| 60% - 69%  | C  |
| 50% - 59%  | D  |
| Below 50%  | F  |
